## The pathway (run in order — no skipping)

### 0 · Spine intake
Capture only what Dale gave + live receipts:
- His words / feeling (law — shape, don’t replace)
- Assets (screens, parent tweet, QT target)
- Constraints (single tweet? no ask? QT vs hero?)

### 1 · WHO
One sentence: who is this for **right now**?  
(current state they’re in — e.g. become-sharp grind / ticket-board / soft-day doubt)

### 2 · PURPOSE (one job only)
Pick **one**:

| Job | When | Ask? |
|-----|------|------|
| **Give / connect** | Milestone, OG proof, soft day honesty | Usually **none** |
| **Educate** | Mechanism / filter / sized vs dump | None or desire plant only |
| **Buzz / engagement** | Forced take, unfinished stake | None |
| **Ask** | After free SPCL already landed (or QT of proof) | Soft trial — **SR only** if used |

If you can’t say the job in one line, you are not ready to draft.

### 3 · Rule of One
Write **one sentence** big idea.  
Run Masterson tests: easy to understand · easy to believe · interesting/unique.  
Everything else must **only reinforce** that idea. Kill toss salad.

### 4 · Pick levers that earn a seat (delete the rest)
**SPCL — own 1–2 max** (Dale law):

| Letter | Use when |
|--------|----------|
| **S Status** | Scarce $ / printer / board we control is the tip |
| **P Power** | Say–do trail / kept showing up / sized → printed |
| **C Credibility** | Hard receipt / third-party grade / public curve |
| **L Likeness** | Always voice — rarely the *content* pillar alone |

**Also seat if they raise the ONE idea:**
- Value equation (dream · likelihood · time · effort)
- Diagnostic (current → desired → obstacle → vehicle)
- Trust (whole truth · proof *is* pudding · show-me)
- Qual (stuff list vs container)

Question each: *What does that mean? How do you know? So what?*  
No evidence → delete.

### 5 · STUFF list (Qual)
Bullet the **receipts** only — live numbers, his words, chart facts.  
No adjectives without observables. Whole truth when it’s the story (misses, worst day, dump).

### 6 · HOOK QA (critical — Hormozi)
Line 1–3 must pass:

1. **Screenshot test** — stranger sees S and/or C in ≤2 lines when $ contrast exists  
2. **What / how / so what** on the open  
3. **Not soft diary** — feelings only after proof, if at all  
4. Prefer proven silhouettes from *our* analytics when they fit (e.g. “Most people try to become sharp” · “EVERY TIME WE WENT OVER 5u” · $ contrast) — never clone empty

If hook fails, **rewrite hook before touching body**.

### 7 · Draft (human)
- Dale dinner-table — not tipster, not brochure, not CAPS spam unless $ contrast earns it  
- Stuff inside > production  
- QT: purpose must use the parent (don’t ignore what’s in the image)  
- Single tweet default; self-reply **only** when PURPOSE = ask

### 8 · Algorithm pass (before showing Dale)
1. Question requirements  
2. Delete until you’d add back  
3. Simplify — most for least  
4. Accelerate — ship 95%  
5. Automate last — never auto-publish  

Kill: meta (“show-me version of the product”) · slogan soup · dunking · system-label leak · inventing numbers

### 9 · Stage
`COPY_PASTE.md` must open with:
- WHO  
- PURPOSE  
- ONE idea  
- SPCL owned (1–2)  
- Ask: none | SR  

Then the copy block only.
