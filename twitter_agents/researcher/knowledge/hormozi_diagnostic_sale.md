## One line

**Sell current → desired. Name the obstacle. Present your vehicle. Tie price to getting them there.**  
Same product; packaging/presentation creates the value.

---

## Customer arc

1. **Agitate / awareness** — pre-sale questions (cost of problem, how long, if it continues).  
2. **Current** — where are you now? (they name it; third-party mirror when possible).  
3. **Desired** — where do you want to be? (**They** set the goal → own the price).  
4. **Obstacle** — what’s in the way? (their words).  
5. **Vehicle + price** — path, time, proof/guarantee; price = cost of the path to *their* goal.  
6. **Step-downs** — prepay benefit first → partial → plan → smallest next yes. Everyone buys something.

---

## Laws

- Not selling the membership / filler / paint / **picks** — selling the **image of the outcome**.  
- After price you’re “a salesperson” — kill objections (**zombies**) *before* price; stay trusted expert.  
- Win the argument → lose the sale. Curiosity > confrontation in the close.  
- Present **high anchor (full path price)** then **prepay savings** (good guy) — not low price + penalty interest (bank).  
- Say **prepay**, never “pay in full.”

## Value equation bridge

| Lever | Diagnostic move |
|-------|-----------------|
| Dream outcome | Desired state *they* named |
| Speed | Time-to-goal in the path (weeks / before tipoff / at lock) |
| Effort | Vehicle removes hate-work; they don’t become the expert |
| Likelihood | Guarantee / proof / public grade / trial |
