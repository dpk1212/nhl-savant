## Core definitions (verbatim operational intent)

- **S Status** — control reinforcers / scarce resources in an environment (bartender example; money continuum).
- **P Power** — say–do correspondence: say → they do → reinforcing event → higher compliance next request. Hormozi’s pick if only one letter.
- **C Credibility** — third-party / hard-to-fake observables (Guinness on launch; building behind ad).
- **L Likeness** — relatability / shared values / look like avatar; be yourself; parents as max-SPCL illustration.

Influence = high likelihood of compliance with a request. Stack all four.

## System laws captured

1. Not enough content + wrong type of content → wrong customers.
2. Content is the targeting (interest media).
3. Views ≠ success for educators; IRL response from ideal avatar is the scoreboard.
4. Volume roughly linear when SPCL boxes checked.
5. More time with prospect = more reinforcement cycles (longs/live ≫ shorts alone; shorts often bridge to longs).
6. Live + interactive = rawer truth → more influence (Hormozi media direction).
7. Domain-specific SPCL; don’t give fashion tips as a money guy.
